# Knight Academy ♟️

A native iPhone app (Swift, SwiftUI, iOS 17+) for learning chess openings,
fundamentals and tactics, and for playing real engine opponents — fully
offline, no account.

## What's inside

| Area | What it does |
| --- | --- |
| **Openings** | 112 distinct openings (Open Games, Sicilian, French/Caro-Kann and other 1.e4 defences, Queen's Gambit and Indian systems, flank openings) with 2,700+ validated lines: hand-written main lines and key variations, traps, plans for both sides, typical mistakes, key positions, plus every named lichess sideline for the opening. Search by name/alias/ECO, filter by side, difficulty, family and learning status. |
| **Variation depth** | Beginner / Intermediate / Advanced / Custom (max plies, number of variations, rare sidelines, trap priority, engine evaluation). The study tree is *generated* from the settings — different settings produce different trees. Progress is stored per move (position + move), so changing the depth never loses progress. |
| **Lessons** | *Learn* mode (move-by-move with explanations and arrows), *Play from memory* (hints in three levels, mistakes explained, retries), practice either side, variation explorer with previews, notes, bookmarks and "practise from here". |
| **Spaced repetition** | SM-2 scheduling per move: accuracy, attempts, streaks, lapses, interval, confidence, frequently forgotten moves, daily review queue. |
| **Fundamentals** | 13 modules / 27 lessons: rules, castling, en passant, promotion, check/mate/stalemate, opening principles, forks, pins, skewers, discovered attacks, deflection, removing the defender, basic mates, king-and-pawn and rook endgames, structures, calculation and planning. Recommendations adapt to weak puzzle themes. |
| **Puzzles** | Engine-verified puzzles with themes, levels, hints, explanations, adaptive selection and a daily puzzle. |
| **Play** | Five bot presets + custom skill/depth/time, colour choice, time controls, take-backs, hints, resign, draw offers, start from an opening / FEN / repertoire, **practise an opening vs a bot that follows the theory** and tells you when you leave it, post-game engine analysis (accuracy, inaccuracies/mistakes/blunders, key moments, eval graph) and move-by-move replay. |
| **Repertoire builder** | White/Black repertoires, add library openings, own moves, preferred moves, notes, PGN import (variations, comments, multiple games) and export, FEN start positions, drills as flashcards or interactive games, play vs bot. |

## Running it

Requirements: macOS with **Xcode 16 or newer** (Swift 6 toolchain), iOS 17+ simulator or device.

1. *(Recommended)* fetch the Stockfish networks, ~75 MB, not stored in git:
   ```sh
   KnightAcademy/Scripts/fetch-stockfish-nets.sh
   ```
   Without them the app still works — bots and analysis use the built-in engine.
2. Open `KnightAcademy/KnightAcademy.xcodeproj`. Xcode resolves the local
   package and `chesskit-engine` (≥ 0.6.0) automatically.
3. Select the **KnightAcademy** scheme and an iPhone simulator, then Run.
   For a device, set your team under *Signing & Capabilities*.
4. Tests: ⌘U in Xcode, or `swift test --package-path KnightAcademy/Packages/KnightAcademyKit`.
   The Stockfish UCI tests run when a `stockfish` binary is on the PATH
   (`brew install stockfish`) and are skipped otherwise.

To rename the app, change `AppInfo.name` (`App/App/KnightAcademyApp.swift`) and
`INFOPLIST_KEY_CFBundleDisplayName` in `project.yml`.

## Regenerating content

```sh
pip install python-chess pyyaml
python3 Tools/openings/build_openings.py --engine $(which stockfish)
python3 Tools/curriculum/build_curriculum.py --engine $(which stockfish)
python3 Tools/puzzles/generate_puzzles.py --engine $(which stockfish) --target 200
xcodegen generate          # after adding/removing app files
```

## Engine & licensing

* Bots and analysis use **Stockfish 17** through
  [ChessKitEngine](https://github.com/chesskit-app/chesskit-engine) (MIT).
  Stockfish is **GPLv3**: distributing a build that contains it requires
  releasing the app's source under GPLv3-compatible terms. A built-in Swift
  alpha-beta engine is the fallback (and is used by tests).
* Bot levels are engine settings (Stockfish *Skill Level*, depth, time). No
  Elo ratings are claimed because they are not calibrated.
* Opening names/ECO/move orders: [lichess-org/chess-openings](https://github.com/lichess-org/chess-openings) (CC0).
* Piece set: cburnett (GPLv2+).
