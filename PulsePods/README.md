# PulsePods

App iOS : fréquence cardiaque AirPods en direct.

- Direct : BPM live, courbe, moyenne/pic/min, moyennes 1/5/15 min.
- Stats : moyenne, pic, min, repos sur 1 h / 24 h / 7 j / 30 j / 1 an (données Santé).
- Séances : historique des mesures.

## Prérequis
- AirPods Pro 3 (ou Powerbeats Pro 2) + iOS 26.
- Autoriser l'accès Santé au premier lancement.

## Installation
IPA non signée → installer via Sideloadly ou AltStore (compte Apple gratuit OK, renouveler tous les 7 jours).
IPA générée par GitHub Actions (`.github/workflows/build-ipa.yml`), publiée en Release.
